# Liver-lipid-analysis
R analysis of liver lipidomic data
I used R to explore the liverlipidome dataset from the lipidomeR package, containing measurements of 383 lipids across 88 liver samples.
I examined one lipid, 1-deoxyCer(34:0), selected alphabetically. I checked sample counts and missing values, calculated medians and interquartile ranges, and created a boxplot comparing Normal, Steatosis, NASH, and Cirrhosis groups.
The code and results are included here.
Data source: https://doi.org/10.21228/M8MW26
